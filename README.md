# Charan Personal Portfolio

This folder is ready to upload to a GitHub Pages repository.

Files:
- index.html
- images/main-1.jpg through main-4.jpg
- images/experience-1.jpg

To publish:
1. Create a repository named YOURUSERNAME.github.io
2. Upload index.html and the images folder.
3. Go to Settings -> Pages.
4. Select Deploy from a branch -> main -> / (root).
5. Save and open https://YOURUSERNAME.github.io
